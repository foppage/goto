# Goto

Add this as a search provider to your browser for better shortcuts.

`http(s)://<YOUR_URL>/s?q=%s`

Built using Go, TypeScript and Docker.

The backend uses the Gin web framework, and the frontend uses Vite + React.

## Running the program

Use Docker. There is an example docker-compose.yml file at the root of the repository. Simply run `git clone https://git.june.pet` followed by `docker compose up -d` to start the program.
